# TP07 - Login e Cadastro com FirebaseUI

Projeto Android em Kotlin com layouts XML utilizando Firebase Authentication e FirebaseUI.

## Funcionalidades
- Login com e-mail/senha e via fluxo do FirebaseUI (`LoginActivity`)
- Cadastro de novos usuários (`CadastroActivity`)
- Tela principal com dados do usuário logado e botão para sair e retornar ao login (`MainActivity`)
